Privacy

What this ticker stores, and what it never sees.

Last updated September 21, 2026. Dynasty Ticker is a static website at dynastyticker.com. It talks to Sleeper from your browser. There is no Dynasty Ticker account.

Who we are

Dynasty Ticker is the open-source project at github.com/nikoskiouris/Dynasty-Ticker. Contact is GitHub issues on that repo, not a mailbox or street address.

What the app fetches

When you search a username or load a league, your browser calls the public Sleeper API for league, roster, matchup, draft, transaction, and player data. KeepTradeCut-style rankings and a Sleeper trade-market file are bundled as static files in this repo. We do not proxy that traffic.

What stays on your device

The ticker uses browser localStorage, not cookies:

  • Light / dark theme
  • A short-lived cache of Sleeper NFL player metadata
  • A local copy of “who would you rather have” picks if the public vote host is unreachable. Live votes are stored on the site host, not only in this browser.
  • Whether you turned on the optional league board, which prices players from this league’s own completed trades.
  • A random id (dynasty_ticker_visitor) used only for the desk tally below

Clear site data in your browser to wipe the local copy.

Public rather votes

Landing-page “who would you rather have” picks are stored anonymously on the site host so they can slightly nudge player values for everyone. A vote is two Sleeper player ids, a format label, and a timestamp. A hashed IP plus browser string is used only to slow spam. Votes do not overwrite KeepTradeCut or Sleeper trade-market files.

Cookies, ads, and the desk tally

This app does not set cookies, does not show ads, and does not install Google Analytics or any other third-party tracker.

The live site keeps its own tally of opens. Your browser stores a random id under dynasty_ticker_visitor and sends it with that tally so a reload counts as the same browser. The host stores a hash of the id, not the id itself. If storage is blocked, the fallback is a hash of the IP address and browser string. The tally also records whether this browser loaded a league or saved a “who would you rather have” pick, the referring site host (not the full link), and whether the open was the home page, a shared league link, or a legal page. It does not store your Sleeper username or the league id. Days roll over at midnight US Eastern. Clear site data to reset the id.

The site host and the Sleeper API may log ordinary request metadata on their side. That is their infrastructure, not a pixel we added.

Share links

Share URLs are ordinary query strings (league, me, tab, week, tone). Anyone with the link can open the same public Sleeper league view. Do not put secrets in the URL. There are none to put.

Children

This is a fantasy-football tool. It is not directed at children under 13, and it does not ask for personal profiles beyond a public Sleeper username you type yourself.

Contact

Questions or deletion requests (for anything we actually control, which is the source code and this policy): open a GitHub issue.
