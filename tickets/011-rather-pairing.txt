Rather pairing still produces no-brainers

Status

Shipped

Priority

Area
Landing rather (`docs/modules/rather.js`)

Description
Desk nudge is the right idea vs a KTC popup. Pairing still puts up fights nobody is taking (example: Deebo Samuel vs Nico Collins).

Tighten “close” so a pair is a real question: similar desk rank *and* similar value *and* similar career stage. Same-position within a small rank gap is not enough if one is a top-5 WR and the other is a WR3. Do not fall back to the two highest names on the board when the close pool is empty — skip or widen the pool without cliffs.

Why
“I’m messing with the desk nudge, it’s def a better concept than KTC because that popup annoys the shit out of me. But it’s comparing Deebo to Nico Collins nobody’s taking Deebo there not sure if the algo is still in progress.”

Current product
`RATHER_MAX_VALUE_RATIO` is 1.12 and rank gap is 8. Same-position pairs get extra weight. If no close pair exists, code can still return the top two ranked players. Crowd votes only nudge value a few percent, so a bad pair stays a bad pair.

Acceptance
- Deebo-class vs Nico-class cannot be a served pair on the current board.
- Skips and recent-pair memory still work.
- If the board has no honest close fight, show skip / “no close matchup” instead of a cliff.
- Add a test: large value and rank gap → weight 0 and never picked.
