# Stop slop

Do not start from "clean", "minimal", or "premium". Those words produce the same cards, the same gradients, and the same dashboard.

## 1. Concept

Name one physical object or place that fits the product. Say it in one sentence before any color or CSS. The object decides type, color, layout, and motion.

A running app can be a track. A sleep app can be a village going dark. A plant app can be a paper cut. A language app can be a deck of playing cards.

## 2. Three directions

Sketch three different objects. Do not blend them. For each, write what the object forces: type, color, layout, and what it refuses.

## 3. Pick one

Keep the direction that can hold every screen. Kill the other two. Do not save their gradients as an accent.

## 4. Render at iPhone size

Draw the real screens at 390×844. Use the concept's type. Safe areas, real hierarchy, and type size that you can read on a phone. Equal cards stacked in a column are not a layout.

## 5. Slop scan

Redo the screen if you see any of these:

- Inter, Plus Jakarta, or one sans used for everything
- Soft gradient blobs, mesh backgrounds, or glow
- Equal rounded cards in a grid
- Icon, title, and subtitle repeated as the layout
- Glass, blur, or soft shadow as the depth
- Purple-to-blue or teal gradient buttons
- Pill buttons and a large radius on every box
- Three feature cards under a hero
- Emoji or generic line icons doing the concept's job
- A dashboard of identical stat tiles
- Everything centered
- Decoration that does not come from the object

## 6. Critique, then refine

Name the weak hierarchy, the repeated pattern, and the spacing that still feels like a template. Change those before shipping.

## Dynasty Ticker

The shipped site keeps its current look until a redesign is asked to replace it. A worked demo of this skill lives at `design/stop-slop/index.html`. It does not publish with the site.

That demo's concept is a pari-mutuel claim slip: dynasty is a futures window, and a score or a trade is paper you hold. The other two directions (film-room chalk, game program) stay visible so the kill is part of the work. Yellow is only a live number. Maroon is the track color, used once per idea, never as a gradient.
